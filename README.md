# 样本偏差诊断看板（Sample Bias Diagnosis Dashboard）

对一份有偏抽样（配送订单场景）做完整的抽样偏差审计：比较样本与总体在**时间、地区、渠道、关键属性**上的分布差异，
提供**加权、分层、缺失回补**三类修正——每种修正生成**独立版本**并展示敏感性，**修正结果永不覆盖原样本**。

## 快速开始

```bash
npm run build     # 生成合成数据 + 运行完整分析（data/ 与 dashboard/data.js）
npm test          # 40 项边界断言：空分层 / 权重异常 / 回补数据 / 不覆盖铁律
# 浏览：直接用浏览器打开 dashboard/index.html（file:// 即可，无需服务器）
```

Node ≥ 18，零运行时依赖（纯原生 JS，浏览器与 Node 同一份内核）。

## 数据设计（确定性合成，种子 20261120）

| 数据集 | 规模 | 说明 |
|---|---|---|
| 总体 `population` | 48,000 单 | 12 周配送订单，7 地区 × 4 渠道 × 4 客群，含金额/履约时长/满意度 |
| 样本 `sample` | 2,000 单 | PPS 有偏抽样：周末/晚高峰、一线城市、App、会员、高金额过抽；满意度 MNAR 缺失、地区 3% MCAR 缺失 |
| 回补 `supplement` | 90 单 | 定向补采低覆盖格子（西北/东北/西南 × 电话/网页 × 工作日），满意度无缺失 |

偏差与缺失都是**机制化生成**的（不是随机噪声），所以诊断与修正的效果可解释、可复现。

## 看板六大板块

1. **概览** — 样本规模、最大 |SMD|、加权 Neff / 设计效应、缺失率四张 KPI
2. **覆盖率** — 各维度格子覆盖率、地区×渠道联合层空层（`西北|电话` 零命中）、12 周时间覆盖趋势、联合层明细
3. **偏差证据** — 分类变量 SMD 发散图 + 卡方齐性检验；连续变量箱线对比 + SMD + K-S 检验；全维度排序
4. **修正方案** — 三个独立版本，各自带方法说明、诊断与局限
5. **比较结果与敏感性** — 4 个业务估计量 × 8 个版本的完整矩阵、权重截断五档扫描、回补并入/剔除对照
6. **异常与边界验证** — 空分层、权重异常、回补数据三类危险输入的处理证据 + 不覆盖铁律的运行时证据

每个图表都配有**表格视图双胞胎**（图表/表格切换按钮），支持深浅双主题，全部数值有 hover 工具提示且键盘可达。

## 四个估计量 × 八个版本

| 版本 | 含义 | 权重/数据列 |
|---|---|---|
| `V0` | 原样本（只读基线，永不修改） | — |
| `V1` | IPF/raking 四维边际校准加权 | `w_weight` |
| `V1t` | V1 权重 P99 截断 | `w_weight_trim`（原值留 `_raw`） |
| `V2` | 地区×渠道事后分层（空层回退、薄层边缘折叠） | `w_strata` + `strataStatus` |
| `V2s` | V2 的薄层收缩敏感性变体（n<30 保持中性权重） | `w_strata_shrink` |
| `V3cc` | 样本+回补，满意度完整案例 | `w_comb` |
| `V3mi` | 样本+回补，M=5 多重插补 Rubin 合并 | `satisfaction_imp`（原列保留 null） |
| `V3ns` | 剔除全部回补的敏感性对照 | `w_comb` |
| `POP` | 总体真值（48,000 单直接计算） | — |

## 不覆盖铁律（架构保证 + 测试守护）

- 所有修正先**深拷贝**样本，再写入**独立的新列**；V0 数组在三个修正全部运行后做 JSON 快照比对（见 `tests/edge-cases.js` 第四节）
- 截断权重保留 `<key>_raw` 原值列；插补值写入 `satisfaction_imp`，原 `satisfaction` 保持 `null`
- 回补记录以 `isSupplement=1` 标记并入，可整组剔除（V3ns），与原样本 `popIndex` 零重叠

## 关键方法与边界处理

| 主题 | 方法 | 边界处理 |
|---|---|---|
| 分类偏差 | 双样本比例 SMD、卡方齐性（期望频数 <5 的格子折叠并计数） | 缺失类别 `__NA__` 显式成行 |
| 连续偏差 | SMD、两样本 K-S（加权 ECDF）、四分位对比 | 缺失率单独报告 |
| IPF 校准 | 迭代比例拟合，200 轮 / 1e-6 容差 | 缺失组按**已知值条件分布**中性处理，口径一致保证收敛 |
| 事后分层 | 单位权重 = 目标占比/实际占比，归一化 Σw=n | 空层标记不可识别并回退地区边缘；薄层（n<30）折叠 |
| 缺失处理 | 渠道×地区单元均值 + 噪声，M=5，Rubin 规则合并方差 | 单元 n<5 回退全局；全缺失场景有测试 |
| 权重诊断 | Kish Neff、Deff、CV、IQR 离群、零/负/NaN 过滤 | 最近秩 P99 截断阈值，五档敏感性 |

## 目录结构

```
src/lib/util.js          确定性 RNG、统计原语、分布/分位数工具
src/lib/generate.js      合成总体 + PPS 有偏抽样 + MNAR 缺失 + 定向回补
src/lib/diagnostics.js   覆盖率、SMD/卡方/K-S、权重诊断与截断
src/lib/corrections.js   V1 IPF 加权、V2 事后分层、V3 多重插补+回补
src/analysis.js          编排：全版本估计量、敏感性扫描、版本血缘
scripts/build-data.js    构建：CSV + 完整 JSON + 看板 data.js
tests/edge-cases.js      40 项边界断言（零依赖 node:assert）
dashboard/               单页看板（index.html + charts.js + app.js + data.js）
data/                    生成产物（CSV / analysis-result.json / 元数据）
```

## 验证方式

- `npm test` — 空分层（含空样本/单条样本）、权重异常（零/负/NaN/极端值/截断不覆盖）、回补（定向命中/无重叠/空回补/全缺失）、不覆盖快照，共 40 项
- 看板渲染另有 21 项 DOM 断言 + 14 项 SVG 几何/可访问性检查（jsdom，脚本在仓库外的临时环境运行）
